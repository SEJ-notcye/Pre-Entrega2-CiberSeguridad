# Pre-Entrega2-CiberSeguridad
Trabajo de curso n°2 de ciberseguridad
En la Captura1 se muestra el usuario Administrador de el lavoratorio virtual. Pasando a la Captura2 se muestra el usuario "indocumentado", nombre elegido porque es el usuario que no tiene derecho de administrador, solo cuenta local, para poder usar esta cuenta con menos privilegios para experimentar y que los experimentos no tengan derechos de administrador. En la captura3 se muestra el Windows Update actualizado al dia con sus parches de sistema y seguridad. En la captura4 tenemos el SMB desactivado para cerrar la brecha de seguridad que este da por su obsolescencia y vulnerabilidad. Luego en  la captura5 snapshot se muestra configurado el Snapshot para recuperar luego de experimentar, para tener asi el sistema limpio de nuevo. Para lo ultimo en la Captura6 red es la configuracion de red puesta en Internal Network luego de actualizar el sistema en "red Nat" (no documentado porque me olvide de hacer la captura), ya que por el momento quiero que la red se encuentre aislada de la red.
